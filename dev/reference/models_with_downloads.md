# Dataset of model names, tasks & download info

- model:

  name of model

- downloads:

  number of downloads

- task:

  task model performsl

- sha:

  model's secure hash algorithm

- private:

  whether model is public or private

## Usage

``` r
models_with_downloads
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with
55524 rows and 5 columns.
