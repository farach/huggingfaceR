# Text2Text Generation Local Inference

Text2Text Generation Local Inference

## Usage

``` r
hf_ez_text2text_generation_local_inference(string, tidy = TRUE, ...)
```

## Arguments

- string:

  a general request for the model to perform or answer

- tidy:

  Whether to tidy the results into a tibble. Default: TRUE (tidy the
  results)

- ...:

  Additional arguments passed internally, including the model object or
  model ID.

## Value

The results of the inference
