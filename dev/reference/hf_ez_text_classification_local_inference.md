# Text Classification Local Inference

Text Classification Local Inference

## Usage

``` r
hf_ez_text_classification_local_inference(string, tidy = TRUE, ...)
```

## Arguments

- string:

  a string to be classified

- tidy:

  Whether to tidy the results into a tibble. Default: TRUE (tidy the
  results)

- ...:

  Additional arguments passed internally, including the model object or
  model ID.

## Value

The results of the inference
